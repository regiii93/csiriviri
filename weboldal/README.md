# Csiriviri weboldal

Ez a kiválasztott változat önálló munkamappája. A további módosítások és az aloldalak itt készülnek. A gyökérmappában lévő `csiriviri-kezdooldal.html` a kiválasztás előtti pillanatkép; a három `koncepcio-*.html` korábbi látványterv.

## Jelenlegi fájlok

- `index.html` — az aktív kezdőoldal.
- `images/` — az oldal által használt képek és logó helyi példányai.

## Következő aloldalak

Az első három szolgáltatási aloldal tervezett neve:

- `szulinapi-zsur.html`
- `arcfestes-csillamtetovalas.html`
- `kezmuves-diszek.html`

Ezek még nem készültek el. A kezdőoldal menüje addig a működő kezdőoldali szakaszokra mutat; az aloldalak elkészültével kapcsoljuk át a megfelelő hivatkozásokat. A bemutatkozás és a kapcsolat külön oldaláról később döntünk.
